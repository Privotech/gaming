# CityVerse NG — 3D Ibadan Open-World Simulation

See the full project documentation in the root [README.md](../README.md).

### Quick Summary
- **Open-World Map**: Real OpenStreetMap 3D generation of Dugbe, Cocoa House, Ekotedo, Gbagi, and Railway Terminus.
- **Vehicle Physics**: Rapier 3D simulation with Danfo Bus, Suzuki Carry (Korope), Saloon Sedan, and NPF Police Cruisers.
- **Police Pursuits**: 1–5 star wanted system, tactical pursuit AI, sirens, and GTA-style Wasted/Busted states.
- **Town Map (`[M]`)**: Interactive district vector map with click-to-set GPS waypoints and Fast Travel.
- **Mixamo Character Support**: Built-in support for Adobe Mixamo rigged characters and converted animations (`anims/`).
- **Street Life**: Roadside hawkers, Amala Bukas, filling stations, bus passenger missions, and Afrobeats radio.
